校園課業小幫手 LINE Bot

串接 Python Flask、LINE Messaging API 與 Google Gemini 3.8 Flash，打造 24 小時在線的智慧課業助教，全面解決 429 配額與冷啟動瓶頸。

GitHub 專案倉庫 ↗ 觀看實測展示

🏗️ 專案介紹與技術架構

專為大學生課後自主學習設計，無需額外安裝軟體，直接在最熟悉的 LINE 介面獲得引導式解題。

💡 專案核心動機

學生在自習與寫程式時經常遭遇卡關，受限於助教 Office Hour 有限與搜尋引擎解答零碎生硬，傳統關鍵字機器人又無法理解自然語言。透過本 Bot 導入生成式 AI，能以啟發性條列方式引導學生思考與除錯。

🛠️ 技術選型與職責

  • 後端服務：Python 3.13 + Flask 輕量 Web 框架
  • 生產級部署：Gunicorn WSGI + Render.com Free Tier
  • 通訊平台：LINE Messaging API (v3 SDK) 數位簽章驗證
  • AI 模型：Google Gemini API (gemini-3.8-flash & 3.5-flash-lite)

🚀 開發瓶頸與改善版架構重構

如實記錄專案從初版遇到 429 與冷啟動，到改善版徹底解決的工程歷程。

⚠️ 初版面臨的痛點

  • Gemini 429 配額耗盡：開啟 Search Grounding 消耗極大，連續發問即撞 RPM/RPD 上限，出現系統繁忙錯誤。
  • Render 15分鐘冷啟動 (Cold Start)：喚醒需 20~50 秒，超過 LINE 10 秒回應門檻，導致伺服器斷線已讀不回。
  • 無快取機制：重複詢問相同觀念不斷重複呼叫 API，浪費寶貴額度。

✅ 改善版的重構解法

  • 模型瀑布降級 (Model Cascade)：主要模型撞 429 時，毫秒級自動切換至低延遲輕量備用模型 (Lite)。
  • 指數退避隨機抖動 (Full Jitter)：依指數遞增等待時間，避免同時間併發打爆 API。
  • 記憶體 TTL 快取 (SimpleTTLCache)：常見問題直接命中快取，0.001 秒極速回傳且耗損 0 次 API 配額。
  • 背景非同步線程 (Threading Worker)：收到請求立刻回 200 OK 給 LINE，後台慢慢產出答案，消滅 10s Timeout！

🤖 AI 協作經驗與工程實踐

記錄在開發過程中如何與 AI 助理進行 Prompt 調整、程式重構與嚴謹檢查。

1. Prompt Engineering（提示詞工程）經驗

初期如果直接使用預設模型，AI 常直接給出過長程式碼或死記硬背的答案。我們設計了專屬的 STUDY_ASSISTANT_SYSTEM_PROMPT：

# 助教規範核心指示
1. 【引導思考與結構化】：條列步驟與觀念推導，不給作弊式死答案。
2. 【程式碼排版】：嚴格要求附帶詳細中文註解與核心邏輯說明。
3. 【手機閱讀體驗】：善用 Emoji 與空行，防範單一訊息超出手機螢幕。

2. 資安防護與邊界除錯經驗

  • 金鑰絕對防洩漏：在 `.gitignore` 嚴格將 `.env` 排除，並使用 `git check-ignore` 反覆驗證，保證公開倉庫 100% 乾淨。
  • Windows 控制台 UTF-8 保護：在 Windows terminal (CP950) 執行時容易發生 Emoji 編碼崩潰，透過 `sys.stdout.reconfigure(encoding="utf-8")` 徹底解決。
  • LINE 訊息長度防護：LINE 單則回覆上限為 5,000 字元，後端在超過 4,000 字元時實施自動安全截斷。
